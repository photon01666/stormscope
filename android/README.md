# Stormscope on Android

Android shell for the same `StormApp` the desktop uses. `GameActivity` (from
AndroidX Games) owns the window, surface, lifecycle and IME; the Rust cdylib
`crates/stormscope-android` is loaded from `MainActivity` and runs
`android_main` via `android-activity`.

> Status: scaffold / early port. The map, radar pipeline and 3D pane are the
> desktop code; touch-specific UI polish (sidebar on a phone, tooltips, window
> sizing) is still to do. The animation ring is capped on Android (8 frames /
> 512 MB) because a phone cannot hold the desktop's 24-frame ring.

## Requirements

- Android SDK 34, NDK 27 (`sdkmanager "ndk;27.0.12077973"`)
- JDK 17 or 21 (AGP 8.7 does not support the newest JDKs)
- `rustup target add aarch64-linux-android`
- `cargo install cargo-ndk`

## Build

```sh
export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.0.12077973"

# 1. Rust cdylib -> android/app/src/main/jniLibs/arm64-v8a/libstormscope_android.so
cargo ndk -t arm64-v8a -P 26 \
  -o android/app/src/main/jniLibs \
  build --release -p stormscope-android

# 2. Package the APK
cd android
./gradlew assembleDebug          # generated once with: gradle wrapper --gradle-version 8.9

# 3. Install on a USB device with debugging enabled
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.stormscope.app/.MainActivity
adb logcat -s stormscope
```

The APK is `android/app/build/outputs/apk/debug/app-debug.apk`.

## Notes

- Package: `com.stormscope.app`; minSdk 26; only `arm64-v8a` is built.
- Cache/config live in the app's private storage (`files/cache`,
  `files/config`); the app has no storage permission and needs none.
- INTERNET is the only permission. All data sources are HTTPS.
- The launcher icon comes from `assets/icon.png` (mipmaps generated by the
  same resizing used for the desktop icon).
- Logs go to logcat under the `stormscope` tag; the desktop binary's stdout
  logging is not used on Android.
